# Information Architecture

## Primary navigation

- Home
- Library
- Authors
- Series
- Genres
- Search
- Favorites (if enabled in MVP)
- Settings

Administrative navigation is separate from normal reading navigation.

## Home

1. Continue Reading
2. Recently Added
3. Library highlights
4. Optional favorites/recent history

## Book detail

- Cover
- Title
- Author(s)
- Series
- Description
- Genres
- Publication/identifier metadata
- Reading action
- Progress

## Reader

Reader chrome should disappear when not needed. Primary controls: back/library, progress/location, TOC/navigation, reader settings, search where supported, and secondary actions.
