# Litera Branding

## Positioning

Litera is a refined self-hosted digital library: simple like Jellyfin/Ubooquity, but centered on an excellent reader.

## Personality

- Editorial
- Elegant
- Calm
- Technical without looking industrial
- Modern without chasing trends
- Accessible and durable

## Design references

Positive: high-quality editorial publications, well-designed ebook readers, library/catalog interfaces, Jellyfin's media-library mental model.

Negative: generic AI dashboards, excessive glassmorphism, gratuitous gradients, dense enterprise administration screens, bookstore/e-commerce visual language.

## Brand principles

1. Content is the visual hero.
2. Typography and spacing create hierarchy before decoration.
3. Motion communicates state; it is not ornament.
4. The interface should feel good on a current device without making an old device obsolete.
5. A lightweight mode is still Litera, not a visually abandoned fallback.

## Voice

Clear, restrained, human, concise. Avoid marketing hyperbole.

## Color and typography direction

Use a restrained editorial palette with strong semantic contrast. Define colors through semantic tokens rather than per-component values. Typography should prioritize readability in long-form content and maintain a distinct display hierarchy for titles.

## Iconography

Simple, consistent line/solid iconography with clear semantics. Avoid decorative icon collections that increase bundle size without improving comprehension.

## Motion

Short, purposeful transitions only. Honor `prefers-reduced-motion`. Legacy mode should remove nonessential motion automatically.
