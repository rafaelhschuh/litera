# Definitions

- **Book file:** physical EPUB/PDF/etc. file on a configured library filesystem.
- **Work/Book:** logical catalog entity representing the bibliographic work, potentially backed by one or more files/editions.
- **Locator:** format-specific position used to restore reading state.
- **Progress:** derived user-facing completion ratio plus the underlying locator.
- **Provider:** external metadata integration.
- **Legacy path:** reduced-capability UI/rendering path selected automatically when the browser/device cannot safely support the full experience.
- **Progressive enhancement:** core functionality works first; richer behavior is added when capabilities permit.
